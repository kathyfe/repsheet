# repsheet

Kathy's workout tracker: quick to log between sets, built for strength and functional training, and syncing to a Google Sheet her Health Coach reads.

- [The app](https://kathyfe.github.io/repsheet/app/): prototype 0.5. Sample numbers until you load your own file. Open it in Chrome on your phone and add it to your home screen.
- [SPEC.md](SPEC.md): what we're building and why.
- [sheet/Code.gs](sheet/Code.gs): the small Google script that files finished sessions in the `repsheet log` Sheet. The real key goes in the deployed copy only.
- [shopping/](shopping/): the weekly shopping list page that Bring! imports.

This repo is public. Code only: no training data, no personal data, no keys. Real routines and weights reach the phone through a private file (see Programme files in SPEC.md).
